# CAE Portfolio

Leaflet-style flipbook portfolio hosted on GitHub Pages.

## Setup

1. Add `portfolio.pdf` (exported from Canva) to this repo.
2. Add `pdflipbook.js` (download from https://symplenz.github.io/PDFlipbook/).
3. Go to Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Visit https://akshpatel9515.github.io/cae-portfolio/
